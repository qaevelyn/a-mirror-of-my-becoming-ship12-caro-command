# A Mirror of My Becoming™ — Ship 12 · Caro Command Deck™

The fleet console for Commander E. Caro: 13 ships, 13 chevrons, one gate — the fleet stands at 12/13, the payload holding for Ship 13.
Tap a ship in the manifest to lock its chevron — lock all 12 and the ring dials,
the wormhole opens, and Ship 13 (TriviaGate™) rides through as the payload.

Single self-contained `index.html`: no build step, no dependencies, no network calls.

## Run it locally

Double-click `index.html`. That is the whole install.

## Put it on GitHub Pages

1. Repo **Settings → Pages**
2. Source: **Deploy from a branch** · Branch: **main** · Folder: **/ (root)** → **Save**
3. Wait about a minute, then your shareable URL is:
   `https://<username>.github.io/a-mirror-of-my-becoming-ship12-caro-command/`

## Updating later

Edit `index.html`, commit, push — Pages redeploys automatically. Keep the filename `index.html` so Pages serves it at the root.
